Privacy Policy

Effective 16 November 2026. Application: Chests Nebula. The operator is the owner of this bot instance.

Data we store

Only what is required to deliver a notification:

  • Discord: the channel id of the direct message or server channel that subscribed;
  • schedule state: the hour shift, the downtime mark, and which notifications were already sent.

The bot does not ask for or store your name, avatar, message history, game login, password, payment details, or friend list.

Why

The id is used to send a message to the chat that subscribed, and to remove that chat when it unsubscribes. Schedule state is used so the same notification is not sent twice and so the shift after maintenance is remembered.

Where it lives

The state file and process logs stay on the operator's server, the machine this bot runs on. Data is not sold and is not sent to advertising networks. Discord receives the message because that is how it is delivered, and processes it under its own rules.

Logs

If delivery fails, the process log may contain the chat id. The log rotates by size and is not used to build a user profile.

Retention

An id is kept while the subscription is active. The /stop command, or removing the bot from a Discord server, drops that chat from delivery. The schedule shift stays with the operator and is not tied to a specific user.

These pages

The terms and this policy are static files. They set no cookies, load no trackers, and do not store IP addresses in a separate database. The web server may write a short technical access log, like any site.

Children

The bot is not directed at children under 13, and it does not knowingly collect their data.

Changes and requests

A new version is published on this same page. If the unsubscribe command is unavailable, ask the owner of the Chests Nebula application in Discord to delete the id. Related document: Terms of Service.
